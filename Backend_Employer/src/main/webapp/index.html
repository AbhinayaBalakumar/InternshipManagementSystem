🔗 IPMS Backend Microservice API

Lab 4 — REST API with JWT Authentication — COE692

Base URL: http://localhost:8080/lab4-backend

🔓 Authentication

POST /api/auth/student-login
Authenticate student credentials. Returns userId and studentName.
😁 PUBLIC — no JWT required
POST /api/auth/employer-login
Authenticate employer credentials. Returns userId and companyName.
😁 PUBLIC — no JWT required

💼 Opportunities

GET /api/opportunities
List all open opportunities. Optional filters: ?company=&title=&skills=
😁 PUBLIC — no JWT required
POST /api/opportunities
Post a new internship/job opportunity. employerId taken from JWT.
🔒 PROTECTED — EMPLOYER JWT required

📋 Applications

POST /api/apply
Apply for an opportunity. studentId taken from JWT (not request body).
🔒 PROTECTED — STUDENT JWT required
GET /api/applications/my-status
Get the logged-in student's application history and statuses.
🔒 PROTECTED — STUDENT JWT required
GET /api/applications/by-opportunity?opportunityId=X
Get applicants for one of the employer's postings.
🔒 PROTECTED — EMPLOYER JWT required
